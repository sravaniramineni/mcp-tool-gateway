# ADR-001: Scoped HMAC tokens + deny-by-default tool registry

## Context
Agents calling enterprise tools need least-privilege access with auditability.

## Decision
Require short-lived scoped tokens per call; deny-by-default registry; sensitive tools
need an approval token; idempotency keys prevent duplicate execution.

## Consequences
- Blast radius of a compromised agent is limited to its scopes.
- Production should move to OAuth/OIDC with a real key store.
